# THE LAST SHIFT

Атмосферный 3D-хоррор от первого лица в браузере. Этап 4: многоуровневый исследовательский комплекс NADIR — внешняя территория с КПП и воротами, главный корпус с четырьмя наземными этажами и три подземных уровня, включая сектор повреждённой экспериментальной капсулы №3.

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm run dev        # http://localhost:5173
```

С телефона: телефон и ПК в одной Wi-Fi сети, откройте адрес `Network`, который напечатает Vite.
Проверить тач-управление на ПК: `http://localhost:5173/?touch=1`.

## Сборка и деплой

```bash
npm run typecheck  # только проверка типов
npm run build      # проверка типов + сборка в dist/
npm run preview    # локальный просмотр сборки
```

Vercel: импортировать репозиторий, пресет Vite определится сам (настройки уже в `vercel.json`).

## Управление

ПК: WASD или стрелки, мышь, Shift (бег), E (действие: двери, осмотр), F (фонарь), Esc (пауза).
Тач: левый палец — движение, правый — обзор, кнопки «Бег», «Действие», «Фонарь».

## Комплекс

| Уровень | Что там |
|---|---|
| Внешняя территория | ворота, КПП, дорога, парковка, подстанция, вентиляционные сооружения, погрузочная зона |
| Этаж 1 | вестибюль, пост охраны, лаборатория А, склад, электрощитовая, серверная, техзона, медблок, изолятор, кабинеты |
| Этаж 2 | административные кабинеты, серверная, комната персонала, картотека |
| Этаж 3 | отдел аналитики, научные кабинеты, обработка данных |
| Этаж 4 | руководство, центр наблюдения, ограниченные зоны |
| Уровень −1 | экспериментальные лаборатории |
| Уровень −2 | изоляторы, камеры содержания, сектор повреждённой капсулы №3 |
| Уровень −3 | серверные, архив исследований, энергетический сектор |

Между уровнями — две лестничные ниши (подъём и спуск) в служебном коридоре.

## Проверки без браузера

```bash
npx tsx scripts/check-layout.ts   # планировка и связность здания с территорией
npx tsx scripts/check-walk.ts     # проход игрока через двери с учётом мебели
npx tsx scripts/check-levels.ts   # связность каждого уровня
npx tsx scripts/check-stairs.ts   # карта лестничных переходов
npx tsx scripts/smoke-world.ts    # построение всего мира, ловит ошибки атласа и материалов
```

Архитектура и решения для следующих этапов: `ARCHITECTURE.md`.
