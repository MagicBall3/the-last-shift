# Проект: The Last Shift

- Стек: Vite + React 18 + Three.js (чистый, без react-three-fiber) + TypeScript. Только npm.
- Запуск: `npm run dev` (порт 5173). Сборка: `npm run build` (tsc --noEmit + vite build).
- Все тексты интерфейса — в `ui/strings.ts` (русский). Игра на русском, не переводить.
- Архитектура: React не знает о Three.js; игра собирается в `game/GameSession.ts` (единственная точка композиции), модули — `GameModule` в `core/Engine.ts`. Новые системы добавляются в GameSession после существующих.
- Мир — данные, а не код: `layout*.ts` (зоны, двери) → `Grid` → `shell.ts`. Новое помещение = прямоугольник в ZONES + дверь в DOORS + обстановка в props.
- Комплекс = 7 уровней в одной сцене (`world/levels/`): 0 — наземный этаж + территория, 1–3 — этажи 2–4, 4–6 — подземные −1…−3. Индекс уровня ≠ номер этажа: подземные идут после наземных. Переходы — `stairs.ts` (`stairTarget`), не арифметика ±1.
- Лестничные ниши имеют ОДНИ И ТЕ ЖЕ координаты на всех уровнях (`STAIR_UP_NICHE`/`STAIR_DOWN_NICHE` в `stairs.ts`). Менять только там — иначе уровни разъедутся по вертикали.
- Свет: каждая лампа помечена этажом (`LightDef.level`), пул берёт только активный этаж. Видимость уровней — `World.applyVisibility` (активный + соседние).
- Проверки без браузера (запускать после правок планировки): `npx tsx scripts/check-layout.ts`, `check-walk.ts`, `check-levels.ts`, `check-collision.ts`, `check-stairs.ts`, `sim-stairs.ts`, `smoke-world.ts`. `check-collision.ts` — единственный тест, который проверяет *многоуровневые* коллизии: что `MultiLevelCollision` выбирает этаж по высоте и что на каждом этаже из лестничной ниши достижимы все зоны (с учётом мебели и дверей). `smoke-world.ts` строит весь мир с заглушкой canvas и ловит ошибки атласа табличек и материалов — самые частые падения. `sim-stairs.ts` — единственный тест с настоящими коллизиями: прогоняет игрока по всем уровням и проверяет приземление. tsx не в devDependencies — ставится через npx.
- Сохранения в LocalStorage, версионируются (`save.version`), проходят sanitize*.
- Решения не менять без причины: см. ARCHITECTURE.md (пул ламп, адаптивное разрешение, тени выключены, процедурный звук).
- Не реализовано намеренно: противник/ИИ, сюжет и задания, интерьеры запертых помещений, шаги/пространственный звук, тени, внешние модели/текстуры.
